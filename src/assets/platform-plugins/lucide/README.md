# Lucide icons

Twelve SVG files are copied unchanged from [lucide-icons/lucide 1.43.0](https://github.com/lucide-icons/lucide/tree/1.43.0/icons).

`shield-code.svg` is a local composition matching the supplied source-scanning reference: the upstream [shield.svg](https://github.com/lucide-icons/lucide/blob/1.43.0/icons/shield.svg) outline contains the upstream [code-xml.svg](https://github.com/lucide-icons/lucide/blob/1.43.0/icons/code-xml.svg) paths, translated by (6, 6), scaled by 0.5, with a 3.5-unit inner stroke before scaling. It is not an upstream icon name.

These files are bundled locally for offline platform plugin cards and rendered inline so `currentColor` follows the Rainbond theme. No runtime package or external image request is required.

The upstream ISC/MIT notices are preserved in [LICENSE](./LICENSE).
